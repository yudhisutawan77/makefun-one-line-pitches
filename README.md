One sentence, 220 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

> That app idea you've been carrying around for years? Describe it in
> plain words and an AI agent on make.fun will build you a real, working
> version for free — no code, no cost, just your idea coming alive while
> you watch.

## How it works

`main.py` writes the entry sentence to `/output/entry.txt`
(or `$ENTRY_OUT/entry.txt` when that is set), checking the gate first:
UTF-8 text, 1 to 240 characters, not only white space.

```sh
python3 main.py
```
